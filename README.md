# CMS-POLL-KH-O-S-T

Bản demo frontend của bảng trắc nghiệm tính cách nghề nghiệp tự đánh giá (MBTI - FORM T0).

## Công nghệ

- Vue 3
- Vite
- Bootstrap 5
- Bootstrap Icons

## Chạy project

```bash
pnpm install
pnpm dev
```

Trang khảo sát: `http://localhost:5173/khao-sat.html`

## Build

```bash
pnpm build
```

Vite được cấu hình multi-page để tạo trực tiếp `dist/khao-sat.html`.
